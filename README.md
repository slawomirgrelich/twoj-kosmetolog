# twoj-kosmetolog

## Edycja aktualności i cennika

Treść komunikatu w polu `aktualnosciTekst` oraz ceny znajdują się w pliku [dane.js](./dane.js). Zmieniaj teksty w cudzysłowach, zachowując przecinki i nawiasy. Nie zmieniaj identyfikatorów kategorii ani oznaczeń grup laserowych. Warianty zabiegów znajdują się w tablicach `warianty`.

Bez JavaScriptu lub w razie błędu pliku danych strona wyświetla awaryjną wersję zapisaną w `index.html`; nie aktualizuje się ona automatycznie po edycji `dane.js`.
